# Premium Sonia I. Guzman Rosario Author Website

## What I’ll build
- A polished five-page literary website: Home, About the Book, About the Author, Gallery, and Contact.
- A shared sticky navigation and editorial footer, with mobile navigation and restrained scroll behavior.
- A cinematic homepage using the supplied full cover artwork, followed by the book introduction, three quote cards, and four exploration links.
- Dedicated book and author pages with clear long-form reading layouts, book details, retailer calls to action, portrait presentation, and pull quotes.
- A filterable gallery with an accessible lightbox, plus a clearly labeled contact form and separate newsletter signup.

## Visual direction
- Use the supplied cover art as the source of truth for the warm editorial mood.
- Apply the requested espresso, ivory, gold, ocean blue, teal, amber, and high-contrast text palette through site-wide design tokens.
- Use Playfair Display for display typography and Lora for body copy, with generous spacing, thin gold dividers, restrained shadows, and readable text widths.
- Keep every page responsive, uncluttered, and legible without placing body copy directly on busy imagery.

## Technical details
- Build with the existing TanStack Start routing structure and create one route per requested page.
- Store the supplied images through the project’s asset system and reuse them without distortion.
- Implement interactions locally: mobile menu, gallery filters/lightbox, contact validation/success feedback, and newsletter feedback. No external form delivery or retailer URLs will be invented.
- Add unique titles, descriptions, Open Graph text, and social card metadata to every content page.
- Verify the rendered desktop and mobile layouts, links, lightbox, and forms, then resolve any reported errors.
